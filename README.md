# ライブラリ更新専用アドオン（lib.guiupdate）

Kodi を DLNA サーバーとして使う場合、音楽ライブラリの更新は GUI 操作でないと反映されない（Kodi 側の挙動。仕様かバグかは未確定）。このアドオンは、その GUI 操作を自動実行するための専用アドオンです。

汎用キーマクロ版 `lib.uodate` の後継として、機能を「ライブラリ更新」だけに絞って作り直したものです。

## 仕様

- **スキャン対象は1つだけ。** 設定画面のボタンから、Kodi に登録済みの音楽ソースの一覧（仮想フォルダ）で選んで登録します。手入力は不要で、選び直せば上書きされます。対象を1つに限定するのは、後のスマートプレイリスト自動読み込みサービスとの兼ね合いによるものです。
- **実行列は固定。** 音楽ファイル一覧を開く → 表示を Wall（500）に切り替え → 登録パスと一致する項目へ直接フォーカス → コンテキストメニューからスキャンを実行、という GUI 操作列だけを行います。位置決め（先頭から何番目、といった相対移動）は使いません。
- **再スキャン確認では「いいえ」を選ぶ**動作（パス限定スキャン）です。全件の再スキャンは手動で行ってください。
- **実行中はマウス操作をロック**します（`input.enablemouse` / `input.enablemouseandtouch` を OFF）。完了時に解除し、万一終了処理まで進まなくても**開始から10秒で自動解除**します。
- 対象が未登録、見つからない、フォーカスできない場合は、誤った項目をスキャンしないよう**中断して通知**します。経過は `kodi.log` に `[lib.guiupdate]` プレフィックスで残ります。

## インストール

このフォルダ（`addon.xml` のあるフォルダ）を Kodi の addons フォルダに置くか、フォルダごと zip にして「zipファイルからインストール」してください。

## 初期設定

1. アドオン設定を開く
2. 「対象フォルダを登録済みソースから選ぶ」ボタンを押す
3. 一覧から音楽ソースを選び、「このソース自体を対象にする」か「サブフォルダを選ぶ」を選ぶ

設定はこれだけです。

## 実行

アドオン一覧から本アドオンを実行すると、登録した対象フォルダのスキャンが GUI 操作で始まります。スキャン自体は Kodi 本体がバックグラウンドで続行します。

## 注意・未確認事項

- 複数パスを持つソース（`multipath://`）を対象にした場合：2026-11-13 に実機で実行し、エラーなく動作しました。複数パス全件のデータ更新までは直接確認していませんが、前身の lib.uodate でマルチパスソースの更新ができていた実績から、問題ないと判断しています。
- ソースのパスに認証情報を埋め込んだ SMB ソースでは、登録されるパスから認証情報が除かれます（Kodi の API の仕様）。認証は Kodi の passwords.xml 等で解決される必要があります。OS 側でマウントしたローカルパスをソースにしている場合は関係ありません。
- 固定の実行列とフォーカス方式は、前身の `lib.uodate` v1.0.10 で検証用 Windows PC（Kodi 22.0-BETA1）と運用 Raspberry Pi 4（Debian 版 Kodi）の両方で動作確認済みです。本アドオン自体も 2026-11-13 に実機で実行し、エラーなく動作しました。
